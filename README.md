# Avinandan — Creative Portfolio

A dark, neon-accented portfolio for Avinandan, showcasing video editing, motion graphics, 3D work, and frontend development.

## About

The site presents Avinandan as a video editor, motion graphics designer, and web developer. It is designed to introduce his work, skills, services, and ways to get in touch.

## Portfolio sections

- **About** — profile and creative focus
- **Skills** — video and audio editing, color grading, motion graphics, 3D, and frontend technologies
- **Services** — commercial video editing, motion design, frontend development, short-form content, brand assets, and 3D animation
- **Portfolio** — video and animation examples, including a cyberpunk teaser, product showcase, SaaS explainer, travel vlog, and short-form reel
- **Testimonials** — client endorsement cards
- **Contact** — email, WhatsApp, Instagram, and a contact form

The visual design uses a dark background, cyan/purple accents, and the Plus Jakarta Sans typeface. A profile illustration is included in `assets/`.

## Technology

The checked-in site is a compiled frontend build. Its artifacts indicate React, Vite, Tailwind-style utility CSS, and Lucide icons. The original source files and dependency manifest are not included, so exact dependency versions and the original build commands cannot be confirmed from this repository.

## Run locally

This repository contains static site files and can be served with any HTTP static-file server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy

Publish the repository's static files to a web server. The HTML loads its scripts and styles from `/assets/`, so the site is configured to be served from a domain root. Hosting it under a repository subpath (such as a GitHub Pages project site) requires adjusting those asset paths or rebuilding with the correct base path; the source and build configuration needed for that rebuild are not present here.
